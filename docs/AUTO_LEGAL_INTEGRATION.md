# 동국 규정과 한국법령 자동 연계 — v0.11.0

`review_finance_case`가 출장비·외부 강사료 질문을 분류하고, 확인된 업무 조건으로 교내 규정과 한국법령을 함께 조회합니다. 금액·소득구분·지급 가능 여부를 자동 승인하는 기능은 아닙니다.

## 질문하는 방법

도구 이름이나 법령 조문 번호를 외울 필요 없이 다음처럼 요청할 수 있습니다. 기준일과 조건은 실제 업무 값으로 바꿉니다.

> 서울캠퍼스 교비회계 직원의 2026년 10월 27일 국내 출장 숙박비를 검토해줘. 교내 여비규정과 비과세 관련 법령을 함께 확인하고, 금액표·예외·추가 확인사항을 보여줘.

> 서울캠퍼스 교비회계에서 외부 강사에게 지급할 강연료를 검토해줘. 기준일은 2026년 10월 27일이고, 학교와 고용관계가 없는 거주자의 국내 일시적 강연이야. 교내 지급 근거와 소득구분·원천징수 법령을 대조해줘.

확인하지 않은 기준일·대상 조건이 있으면 먼저 질문합니다. 이미 제공한 사실을 다시 입력할 필요는 없습니다. 단순히 “취업규칙 제62조를 보여줘”라고 하면 해당 규정만 조회하면 됩니다.

## 자동 분류 범위

| 업무 | 교내 규정 | 법령 후보 | 남는 확인사항 |
|---|---|---|---|
| 교원·직원 출장비 | 여비규정 또는 확인한 별도 지급 규정 | 소득세법 제12조·시행령 제12조 | 출장 목적·정액/실비·실제 지출·중복 보전·캠퍼스·표의 단위 |
| 국내 용역·거주자 외부 강사료 | 위임전결규정으로 결재 절차 확인, 별도 확인한 지급 규정 추가 | 소득세법 제19·20·21·127조 | 고용관계·활동의 계속성·독립성·계약·지급 기준 |

법령 조문은 2026-10-27 실제 원문으로 명칭과 내용을 확인해 만든 **조회 후보 연결표**입니다. 각 호출은 업무 기준일의 버전을 다시 조회하며, 후보 선정이 곧 적용 확정은 아닙니다.

- 강사료라는 명칭이나 일시 지급만으로 기타소득을 확정하지 않습니다.
- 위임전결규정은 강사료 단가의 근거가 아닙니다. 별도의 지급 기준이 확인되지 않으면 `HONORARIA_PAYMENT_RULE_UNCONFIRMED`와 `partial`을 남깁니다.
- 급여·퇴직연금·비거주자·국외 강연·산학협력단·병원·수익사업은 일반 교비 기준으로 대체하지 않고 별도 조회로 분기합니다.
- 국외 출장은 지원하지만 여비표·실비 조건을 별도로 확인합니다. WISE는 규정의 적용범위를 확인하라는 안내를 남기며 서울 기준으로 확정하지 않습니다.
- 출장비와 강사료가 한 질문에 섞이면 각각 나누어 조회합니다.

## 출처와 조회 실패 표시

답변에 교내 규정과 법령 본문을 모두 표시합니다. 규정 ID·개정본 ID, 법령 MST·시행일·기준일·원문 링크와 잘림·누락 상태를 함께 확인합니다. 한쪽 조회가 실패해도 다른 쪽의 근거를 남기며 `partial`로 표시합니다.

한국법령 조회에는 기본 45초의 전체 시간 제한이 있습니다. 이미 확보한 결과를 보존하고 남은 요청은 `LEGAL_TOTAL_TIMEOUT`으로 표시합니다. 각 요청의 기본 제한은 25초이며 전체 잔여시간을 넘기지 않습니다.

과거 별표는 한국법령 서버의 날짜 입력 지원을 확인한 뒤 조회합니다. 응답의 기준일·시행일·MST를 독립적으로 조회한 당시 법령 버전과 대조합니다. 검증되지 않은 현행 별표를 과거의 확정 근거로 취급하지 않습니다. 개정일·시행일·경과조치와 개별 사안의 적용성은 구분합니다.

## 연결 설정

공개 `rules` 프로필과 `/mcp/rules`는 기존 10개 도구를 유지합니다. 자동 연계는 선택한 `finance` 프로필의 기존 도구를 사용하며 도구 수는 14개입니다. 내부 자료팩 없이 출장비·강사료의 공개 원문 공동 조회를 사용할 수 있습니다. 해설서·실무팩·기존 카드 기능은 별도 설정이 필요합니다.

원격 한국법령 MCP를 사용할 때 필요한 설정:

```text
DONGGUK_LEGAL_MCP_ENABLED=1
DONGGUK_LEGAL_MCP_TRANSPORT=streamable-http
DONGGUK_LEGAL_MCP_URL=https://korean-law-mcp.fly.dev/mcp
```

인증이 필요한 운영 서버에는 `DONGGUK_LEGAL_MCP_BEARER_TOKEN`을 별도 접근제한 설정으로 지정합니다. URL·질문·공개 저장소에 인증정보를 넣지 않습니다. 원격 연결에는 HTTPS를 사용하며 로컬 회귀검사용 loopback HTTP만 예외입니다. HTTP 모드는 `LAW_OC`를 요구하지 않습니다. 기존 stdio 방식과 `LAW_OC` 사용 방식도 유지합니다.

이름·계좌·개인번호를 외부 법령 서비스에 보낼 필요가 없습니다. 통합 기능은 선정한 법령명·조문·기준일로 한국법령을 호출합니다. 공개 원문만 사용할 로컬 연결에서는 학교 쿠키와 내부 자료팩 경로를 비워 둡니다.

## Codex 자동 도구 선택

패키지의 `skills/dongguk-rule-law-review`를 Codex 스킬 폴더에 설치하면 관련 업무 질문에서 자동 선택할 수 있습니다. 일반 규정 열람, 출장·강사료 공동 조회, 지원 범위 밖 직접 법령 조회, 인용 점검을 구분합니다. 직접 호출하려면 `$dongguk-rule-law-review`를 사용합니다.

서버·스킬 설정을 바꾼 후에는 새 대화 또는 앱 재시작으로 다시 로드합니다. 설정 등록, 실제 MCP 호출 검증, 현재 대화에서의 도구 사용 가능 여부를 구분합니다.
