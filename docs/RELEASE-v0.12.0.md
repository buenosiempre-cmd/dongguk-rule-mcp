# v0.12.0 — HWP 원문과 구조 비교

같은 규정의 두 개정본을 비교할 때 HWP 조문을 우선 사용합니다. HWP를 읽지 못한 경우에만 HTML 조문으로 대체하고, 대체 사유와 부분 상태를 반환합니다.

- 별표·서식 텍스트에 더해 표 셀의 행·열 좌표, `rowSpan`·`colSpan` 병합 범위, 값을 비교합니다.
- 포함된 그림 파일의 SHA-256 해시로 파일 내용의 동일·변경을 비교합니다. OCR, 그림의 의미 해석, 페이지 배치 비교는 포함하지 않습니다.
- 문서별 추출 범위와 미지원 객체·누락 진단을 제공합니다. 일반적인 한계 문구만으로 모든 병합 셀·그림을 미확인 처리하지 않고 실제 비교 결과와 부분 사유를 구분합니다.
- 원문 캐시를 `original-structure-v1`로 분리해 이전 텍스트 전용 캐시가 새 구조 분석을 가리지 않도록 합니다.
- 설치 런타임·공용 서버·실제 앱 연결의 버전을 각각 확인하는 갱신 절차를 문서화합니다. 기존 Codex 연결은 앱 재시작 후 검증하고, Aside 도구 목록은 공식 설정 API로 보존하며 갱신합니다.

기본 `rules` 10개 도구와 선택 `finance` 14개 도구, 기존 한국법령 연계, 인증 경로와 내부 자료팩의 분리는 유지합니다. 시행일·경과조치·업무 적용성은 비교 결과와 별도로 검토합니다. 미지원 객체나 추출 실패로 남은 부분 상태를 “변경 없음”으로 해석하지 않습니다.

이 문서는 변경 기능을 설명합니다. 테스트 통과, 릴리스 게시, Mac mini 배포, 각 앱의 실제 연결 갱신 여부는 해당 실행 결과와 배포 기록으로 확인합니다. 검증·갱신 절차는 [운영 가이드](OPERATIONS.md)를 참고하세요.
