## 작성 근거와 분모

- 2026-11-28 별도 MCP에서 기준 ee501b6의 공개 응답을 수집하고, E 수정본 3b6cb78에 동일 응답을 재생했습니다. 대학 외부 요청 83건의 요청 키·순서는 동일합니다. 수집 5회는 대학 4곳을 묶은 호출이며 각 문항의 단일 대학 args는 이후 개별 검수용입니다.
- 각 사례의 observed는 도구가 반환한 관찰값입니다. **관찰값을 정답으로 자동 복사하지 않습니다.** 정답 후보는 제목과 조문 내용을 읽어 선별한 초안이며 모두 교차 검수가 필요합니다.

- 현재 개발자가 본 공개 사례이므로 독립 평가·보류셋이 아닙니다. 새 45문항·이 셋에 맞춰 제품 가중치를 조정하지 않습니다. 비공개 문항은 읽지 않았습니다.
- 기대 조문을 찾지 못한 경우 규정 부존재로 판정하지 않습니다. 여러 규정이 필요한 경우 같은 기관 범위인지 확인하며, 대학 내 특정 판 하나를 일반판으로 대체하지 않습니다.

1. 정답 후보: 상위 3개에 정확한 대학·규정·조문이 있는지, 첫 발췌가 직접 사안인지 별도로 기록합니다. 인용만 있는 보조 조문으로 대체하면 실패입니다.
2. 오탐 대조: 시설 사용 제한을 법인카드 제한 근거처럼 내지 않는지 봅니다. 제외하거나 명시적으로 약한 후보라고 표시하면 안전한 보류로 기록하며, 정답 검색 성공과는 별도 집계합니다.
3. 입력 모호: 재무 증빙과 학사·업적 증빙을 혼동해 확정하지 않는지 봅니다. 추가 맥락 없이는 규정 정답을 승인하지 않습니다.
4. 원문 추가 확인: 현재 분모에서 제외합니다. 규정 목록·공식 원문으로 기대 조문을 추가하고 교차 검수한 뒤 편입합니다.
5. 내용 정확성·시행일·별표 누락·접속 실패·추가 조회 횟수는 정답 조문 여부와 별도 항목으로 집계합니다.
