# 목적·적용범위 본문에 의한 판 보강 실험

상태: 최종 공통 캐시 전환 후 비교 완료. **생산 도입 비권고**: 개선0, 신규오답은 의미검색 on의 Z137·off의 K02. [전체 결과](body-scope-results.md)에 조건별 전수 변경을 기록했다. 기본은 `legacy`이며 기존 `hybrid` 동작도 유지한다. `DONGGUK_MCP_RANKING=hybrid-scope`만 본문 근거를 사용한다. 법적 적용을 확정하는 기능이 아니다.

## 모듈과 훅

- `src/scope.js`: `inferRuleScope(rule)`, `scopeAgreement(scope, request, title)`, `createScopeSignal({corpus})`.
- 기존 ontology의 캠퍼스·기관 어휘를 재사용한다. 문항·특정 규정번호를 조건으로 쓰지 않는다.
- `fusion.js`의 `placedEditions`에 선택적 agreement 콜백만 연결했다. t110의 판 선택 알고리즘·배수·후보 처리 방식은 그대로다. `corpus.js`·`index.js`는 선행 merge 외에 변경하지 않는다.
- corpus 객체별로 판정표를 한 번 만들고 WeakMap으로 재사용한다. 없는/손상 corpus는 기존 제목 판정으로 폴백한다. 판정 객체는 불변이다.

## 규칙과 보수적 제한

본칙의 처음 3개 블록 중 목적·적용범위·적용대상·범위·대상 제목만 검사한다. 부칙과 소재·직능·구성·일반 설명은 대상이 아니다. 법령·규정의 낫표 인용은 제거하고, 명시적 대학/본교 캠퍼스 소유 문구 또는 적용대상 절을 읽는다. 앞선 인용 근거와 실제 적용대상 절을 구분한다.

예외·부정·다만 문구나 복수 캠퍼스가 섞여 대상이 불명확하면 body 판정을 보류한다. 두 캠퍼스에 명시적으로 적용하는 본문은 특정 캠퍼스 전용판으로 가점/감점하지 않는다. 제목에 판이 이미 명시됐으면 제목을 보존하며 본문 충돌은 별도 표시한다. 알 수 없음은 전교 적용 확정이 아니다. 순위에서는 종전과 같이 중립값을 사용한다.

기관의 연구비 관리·사업 주관 관계만으로 기관 전용판이라고 판단하지 않는다. 기관 소속 구성원에 대한 직접 적용이나 기관 자체의 조직·운영·설치·인사·복무를 직접 정하는 목적 문구만 채택한다. 따라서 현재 개발 corpus에서는 본문 기관 추가 확정이 0개다. 소재 조문 제외, 처음 3개 제한, 생략된 주어·기관명 미해결 등으로 일부 실제 판을 놓칠 수 있다. 이 제한을 정답 문항별 예외로 보완하지 않는다.

판정표는 모든 규정의 lawId/historyId/제목, 축별 값·근거 출처·상태, 조문·원본 블록 위치·인용 및 채택/보류 사유를 보존한다. 정보 없음·모호·충돌도 누락하지 않는다.

## 개발 판정표 및 측정 준비

`node scripts/audit-rule-scopes.js <corpus.json> <새 출력.json>`은 질문을 읽지 않고 전체 규정 판정표를 저장한다. 기존 D1 corpus `59c2e11fe66e…`의 개발 점검에서는 513규정 중 캠퍼스 제목117·본문50·미확정346, 기관 제목27·본문0·미확정486, 예외 등 모호14·제목 충돌0이었다. 정확도나 효과 수치가 아니다. 초기 기관 추출의 관리 주체 오인을 검토한 뒤 보수적으로 제한했다.

최종 공통 corpus `830b6996…`와 vector `fd7d662b…`로 비교했다. 아래처럼 두 방식을 각기 독립 캐시 사본에서 재현할 수 있다.

```sh
node scripts/measure-body-scope.js --cache <자체 사본 루트> \
  --questions <scope12,scope22,공개251,probe9,dev_open의 파일 목록> \
  --ranking hybrid-scope --query-only --out <새 결과.json> \
  --expected-corpus-sha <공지된 전체 SHA256> --expected-vector-sha <공지된 전체 SHA256>
```

비교 기준은 `--ranking hybrid`다. 질문만 조건은 args.keywords도 무시한다. 새 공통 corpus·벡터 SHA를 모두 명시해야 실행할 수 있다. 결과에는 실제 사용 파일명·TEXT 버전·커밋·소스 해시·문항 해시와 규정별 전수 판정표를 넣는다. strict/top3/조건부 조문/1위·모든 신규오답·개선·반환 순서 변화를 세트별로 보고한다. scope22는 t110 공개 개발 Z121~Z142의 데이터 선택이며 런타임 규칙과 무관하다. 박스 보류셋은 읽지 않는다.

최신 PR60 `7d13345`와의 충돌은 merge `702dbce`로 해소했고, 같은 규칙으로 최종 공통 캐시에서 다시 비교했다. 본문 판정513개와 모듈 해시는 merge 전후 동일하다. 현재 결과는 [최신 하네스 보고](body-scope-results.md), 지정 f0b355f 기준의 이전 결과는 [별도 기록](body-scope-results-f0b355f.md)으로 구분한다.
