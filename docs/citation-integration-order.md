# 날짜 부칙 인용 상태 계약

인용된 날짜는 부칙 머리의 개정일을 식별한다. 시행일이나 실제 사안의 적용 여부를 판정하지 않는다.

| 상태 | 의미 | 집계 |
|---|---|---|
| `ARTICLE_SELECTOR_UNVERIFIED` | 인용의 날짜 선택자를 해석하지 못하거나, 일치 날짜를 찾지 못한 상황에서 원문에 날짜 미상 부칙이 있어 실존을 판단할 수 없음 | ⚠, `needsReview`에 포함. `verified`·`exists`·`notFound`에서 제외 |
| `NOT_FOUND` | 확인 가능한 부칙 날짜·조문 구조에 인용된 날짜 또는 조문이 없음 | ✗, `notFound`에 포함 |
| `ARTICLE_AMBIGUOUS` | 날짜 없는 인용에 같은 조문 번호의 부칙이 여러 개 대응 | ⚠, `needsReview`에 포함 |

`부칙에 따라 시행하며, 제3조를 준용한다`와 같은 문장은 본칙 제3조를 검증한다. 부칙 선택자의 접두부는 바로 붙은 괄호·꺾쇠 묶음 또는 날짜 표기까지만 읽는다.

summary 키와 기존 상태의 의미는 유지한다. 확인필요는 검증 성공이 아니다. 재무 검토 소비자는 `needsReview`·`notFound`·`floating`·`truncated`를 함께 확인한다.

`부칙(날짜)의 제1조`와 `부칙(날짜) 중 제1조`도 같은 날짜 선택자로 처리한다. 연결 표현이 있어도 부칙 날짜를 버리고 본칙으로 바꾸지 않는다.
