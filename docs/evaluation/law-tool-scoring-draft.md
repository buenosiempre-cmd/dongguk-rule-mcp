# 상위 법령·인용 관계 공개 채점 초안 (2026-11-28)

각 20건, 합계 40건의 **개발용 초안**이다. main `ee501b6`, v0.15.13을 대상으로 하며 생산 코드는 바꾸지 않는다. 공개 규정 8개/원문 발췌 10개를 여러 설정·장애 조건에서 반복한다. 독립적인 40개 규정이나 서비스 전체 정확도를 대표하는 표본은 아니다. 보류셋·비공개 질문은 사용하지 않았다.

## 파일과 재현

- `test/fixtures/law-tool-scoring/upper-laws.json`: 상위 법령 U01–U20
- `test/fixtures/law-tool-scoring/references.json`: 인용 관계 R01–R20
- 같은 폴더 `sources.json`: dongguk-rule MCP에서 받은 공개 원문, LAW_ID/HISTORY_ID, 개정일, URL, 원 캡처 SHA256. 개정일을 시행일로 바꾸지 않는다.
- `legal-captures.json`: korean-law MCP의 공개 검색·본문 응답. 캡처 시점 2026-11-27/28의 고정 자료로, 실행일의 현행 법령을 뜻하지 않는다. 법령명·MST·시행일은 응답에 보존했다. 자격증명은 포함하지 않는다.

```sh
node test/test-law-tool-scoring-fixtures.js
node scripts/score-law-tools-draft.js /absolute/path/to/new-evidence-directory
```

출력 디렉터리는 새 경로여야 한다. 각 문항은 별도 프로세스·캐시에서 실제 MCP handler와 법령 클라이언트를 실행한다. 외부 네트워크는 막고, 공개 규정 스냅샷과 고정된 한국법령 MCP 응답을 재생한다. 조회 인자에 기록되지 않은 법령 호출이 생기면 채점 실패로 남긴다. 문항별 인자·도구 호출·전체 응답과 `summary.json`을 저장하며 삭제하지 않는다. 종료 코드 0은 전건 통과, 1은 실패가 있다는 뜻이다.

## 채점 계약

각 문항은 `arguments`, `source`, `condition`, `expectedLaws`(규정 원문에 적힌 법명·조문), `expected`(구조화 필드 경로와 기대 상태), `rationale`로 구성한다. 인용의 존재와 현행 여부·본문 확보·사건 적용을 분리한다. 원문을 먼저 읽고 인용 정답을 정했으며, 구현의 응답을 그대로 정답으로 저장하지 않았다.

- U01–U07/R01–R07: 국가 법령 인용 추출. 정관 제44조의 무낫표 `병역법`도 명시적 법명으로 기대한다. 조문이 쓰여 있지 않으므로 법령 본문 조회 대상은 아니다. 긴 `및` 법명은 공식 대조 전에는 `nameGuessed`·`nameCandidate`를 유지한 후보만 인정한다.
- U08–U10/R08–R10: 국가 법령 인용 없는 대조. 취업규칙 제50조는 교내 여비규정 인용이고, 교직원 수당 규정 제4조는 예산편성지침 위임이다. 국가 법령으로 승격하지 않는다.
- U11–U16/R11–R15: 현행 본문, 연계 꺼짐, 제공자 장애, 시행 전 본문, 제목만 있는 응답, 본문 누락. 고정 기준일은 2026-11-28. 산업안전보건법 목록 시행일 2026-10-27과 본문 시행일을 대조한다. 오류 본문을 반환하거나 `retrieved`로 완전 표시하면 실패다.
- U17/R17: 옛 `지가공시 및 토지 등의 평가에 관한 법률` 인용. 법명 변경과 조문 번호의 동일성 미확인 경고를 확인한다. 현재 조문을 과거 조문과 같은 것으로 판정하지 않는다.
- U18/R16/R18: 약칭 괄호·같은 조문의 법/시행령 연결·긴 법명. 고정 제32조 본문은 2,566자로 상위 법령의 3,000자 한도 미만이다.
- U19/U20: 잘못된 조문 인자와 법령 수 한도. 일부 생략을 전체 조회로 표현하지 않는다.
- R19/R20: 역방향 인용. R19는 공개 원문으로 만든 **2개 규정의 테스트 색인**에서 취업규칙 제50조 → 여비규정 연결을 요구한다. 전체 공식 코퍼스의 incoming 건수 정답으로 사용하면 안 된다. R20은 색인 없음이 인용 0건 확정과 다름을 확인한다.

문항 전체 통과는 필요한 인용과 상태 검사를 모두 통과한 경우다. 별도로 법명/조문 누락, 출처 오귀속, 조회 상태 과장, 인용·본문 혼동을 유형별로 기록한다. 이 초안의 자동 검사는 핵심 인용의 포함과 지정 필드를 검사한다. 모든 불필요한 인용·경고 문구의 표현·대상 판본의 모든 부칙을 완전 채점하는 것은 아니다. 법적 충돌·최종 적용의 정답은 만들지 않는다.

## 의도적으로 남긴 실패와 한계

무낫표로 조문 번호 없이 쓰인 `병역법에 의한 ...`(정관 제44조 제2호)을 현 구현이 추출하지 못하는지 확인한다(U05·R05·R18). 이 항목을 구현에 맞춰 정답에서 제거하지 않는다. 초안 채점의 실패는 생산 코드 수정 요청이나 배포 승인으로 간주하지 않는다.

제목만 있는 응답과 장애는 합성 조건이다. 미래 시행 본문은 과거 공식 MCP 응답을 현재 목록 응답과 의도적으로 조합한 장애 재현이다. 실제 서비스가 지금 같은 장애를 보인다는 뜻은 아니다. 매 문항 새 캐시이므로 장기 캐시 오염·재시도 회복·동시 호출·최대 시간·페이지 이동·8개 초과 조문은 이 초안 범위 밖이다. 공개 서버 전체 호출 대신 소수 확인과 오프라인 재생을 사용한다.

`npm test`는 파일 형식·출처 연결·문항 수 검사를 포함한다. 전체 40건의 기대 동작 채점은 위 별도 명령으로 실행한다. 기존 결함이 드러난 채점 실패를 CI 성공으로 숨기지 않고 보고서에 문항 ID로 함께 기록한다.
