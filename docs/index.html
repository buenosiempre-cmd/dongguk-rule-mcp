내 PC · v0.15.8

npm 레지스트리는 미발행입니다. Node.js 20.19 이상 20계열 또는 22.3 이상.

npm install -g https://github.com/buenosiempre-cmd/dongguk-rule-mcp/releases/download/v0.15.8/dongguk-rule-mcp-0.15.8.tgz
dongguk-rule-mcp --doctor --json
dongguk-rule-mcp --print-config claude
dongguk-rule-mcp --print-config cursor

--print-config의 command는 그 PC의 Node 절대 경로입니다. 앱 설정 파일은 바꾸지 않습니다.

자주 묻는 질문

학교 공식 서비스인가요?

아닙니다. 재무팀 개인 운영 도구입니다.

왜 npm install 이름이 없나요?

npm 레지스트리는 현재 미발행입니다. GitHub 릴리스 tgz v0.15.8 또는 공용 주소를 사용합니다.

캠퍼스별로 자동 검색되나요?

아닙니다. campus 값은 업무 맥락만 보존합니다. 적용범위는 원문에서 확인합니다.

다른 대학 비교는 항상 켜져 있나요?

아닙니다. DONGGUK_UNIVERSITY_COMPARISON_ENABLED=1 일 때만 요청이 나갑니다. 법적 동등성을 판정하지 않습니다.

개인정보를 넣어야 하나요?

넣지 않습니다. 개인번호, 계좌, 인증정보는 거부됩니다. 신고·지급·결재는 하지 않습니다.
