설치: 주소 하나만 넣으면 됩니다

내 PC에 아무것도 설치하지 않습니다. 쓰는 AI 앱에 아래 공용 서버 주소를 등록합니다. 로그인도 토큰도 없습니다.

https://dgu.kr-univ-rules.com/mcp/rules

공용 서버에서는 규정 도구 15개가 모두 켜져 있습니다. 접속한 IP마다 1분 60회, 하루 1,000회까지 받습니다.

Claude Desktop

  1. Customize(사용자 지정) > Connectors(커넥터) 화면을 엽니다.
  2. + Add를 누르고 Add custom connector(사용자 지정 커넥터 추가)를 고릅니다.
  3. 이름은 동국 규정, 주소는 위 주소를 넣습니다.
  4. Authentication(인증) 항목에서 No sign in(로그인 없음)을 고르고 추가합니다. 이 서버는 인증이 없습니다.

화면이 다르면 Anthropic 공식 안내의 현재 절차를 따르세요. 메뉴 이름과 위치는 앱 버전에 따라 다를 수 있고, 회사·학교 계정은 관리자가 먼저 추가해야 할 수 있습니다.

연결 확인

앱을 다시 시작한 뒤 이렇게 물어봅니다.

동국 규정 MCP가 연결됐는지 확인하고, 여비규정에서 국내 출장 숙박비 기준을 찾아줘.

버전과 도구 수(15), 그리고 규정명·조문·원문 링크가 붙은 답이 오면 연결된 것입니다.

재무 도구가 필요한 구성원. 재무 업무용 도구 4개가 더해진 주소(https://dgu.kr-univ-rules.com/mcp)는 구성원 토큰이 있어야 열립니다. 토큰은 운영자(동국대 재무팀 담당자)에게 개별 요청하세요. 받은 토큰은 앱 설정의 인증 헤더(Authorization: Bearer <발급받은 토큰>)에만 넣고 문서·채팅·저장소에는 적지 않습니다.

두 번째 선택지: 내 PC에 설치 (v0.15.8)

공용 서버를 쓸 수 없거나 내 PC에서 직접 돌리고 싶을 때만 씁니다. Node.js 20.19 이상 20계열 또는 22.3 이상이 필요합니다. npm 레지스트리에는 발행하지 않았습니다.

npm install -g https://github.com/buenosiempre-cmd/dongguk-rule-mcp/releases/download/v0.15.8/dongguk-rule-mcp-0.15.8.tgz
dongguk-rule-mcp --doctor --json
dongguk-rule-mcp --print-config claude

--print-config 뒤에는 claude, cursor, codex 중 쓰는 앱을 적습니다. 그 PC의 경로로 만든 설정을 보여 줄 뿐 앱 설정 파일은 바꾸지 않습니다. 나온 내용을 앱의 MCP 설정에 붙여 넣고 앱을 다시 시작합니다.

현재 배포본(v0.15.8)을 내 PC에 설치하면 규정 조회 도구는 바로 동작합니다. 타대학 비교와 인용 법령 조회는 앱의 MCP 서버 설정에 아래 환경변수를 넣어야 동작합니다. 넣지 않으면 그 기능만 설정되지 않았다고 답하고 규정 조회는 그대로 됩니다.

  • 타대학 비교: DONGGUK_UNIVERSITY_COMPARISON_ENABLED=1. 서울대까지 보려면 DONGGUK_LAWGO_OC(법제처 Open API 인증키)도 필요합니다.
  • 인용 법령의 원문·현행 여부: DONGGUK_LEGAL_MCP_ENABLED=1, DONGGUK_PUBLIC_LAW_LINK=1과 함께, 한국법령 MCP 주소(DONGGUK_LEGAL_MCP_TRANSPORT=streamable-http, DONGGUK_LEGAL_MCP_URL) 또는 법제처 Open API 인증키(LAW_OC, PC에 korean-law-mcp 설치 필요).

인증키는 open.law.go.kr에서 신청합니다. 공용 서버에는 이 설정이 모두 들어 있어 따로 할 일이 없습니다.

어떻게 동작하나요

① 질문"여비규정에서 숙박비 기준 찾아줘"처럼 평소 말로 묻습니다. 도구 이름을 외울 필요는 없습니다.
② AI 앱이 도구 호출MCP는 AI 앱이 바깥 자료를 읽게 해 주는 연결 방식입니다. 앱이 질문에 맞는 도구를 골라 공용 서버에 요청합니다.
③ 공용 서버가 원문 조회누구나 볼 수 있는 rule.dongguk.edu의 공개 원문을 그때그때 읽습니다. 로그인이 필요한 자료는 읽지 않습니다.
④ 조문과 출처로 답규정 이름, 조문·별표 위치, 개정일, 원문 링크가 함께 옵니다. 링크로 원문과 대조할 수 있습니다.

읽기만 합니다. 신고·지급·결재·발송은 하지 않습니다. 개인번호, 계좌, 인증정보는 질문에 넣지 마세요.

도구가 하는 일

도구는 AI 앱이 알아서 고릅니다. 15개 모두 읽기 전용이고 공용 서버에서 모두 켜져 있습니다.

도구하는 일이렇게 물으면 씁니다
lookup_dongguk_rule질문에 맞는 규정을 찾아 관련 조문과 별표를 보여 줍니다. 대부분의 질문은 여기서 시작합니다여비규정에서 국내 출장 숙박비 기준 찾아줘

get_rule_content이미 고른 규정에서 특정 조나 장을 보여 줍니다여비규정 제5조 보여줘
get_rule_full_text규정 하나를 부칙·별표·서식까지 처음부터 끝까지 보여 줍니다. 긴 규정은 여러 번에 나누어 가져옵니다위임전결규정 전문을 보여줘

compare_rule_versions두 개정본을 비교해 바뀐 조문과 별표를 보여 줍니다여비규정이 직전 개정에서 뭐가 달라졌어?

search_rule_deep여러 규정의 본문을 한꺼번에 검색합니다'겸직'이 나오는 규정을 모두 찾아줘

get_rule_references규정이 인용한 다른 교내 규정·국가 법령과, 이 규정을 인용한 규정을 찾습니다. 인용한 법령 조문의 원문도 가져올 수 있습니다여비규정이 인용하는 법령과 그 조문을 보여줘
get_rule_upper_laws규정이 근거로 든 법령이 지금도 그대로인지(현행·삭제·개정) 점검합니다이 규정이 근거로 든 법령이 바뀌었는지 봐줘
compare_university_rules같은 주제의 조문을 다른 대학(한 번에 최대 5곳) 규정과 나란히 보여 줍니다겸직 허가 기준을 고려대·연세대와 나란히 보여줘
get_service_info연결 상태, 버전, 켜진 기능을 알려 줍니다동국 규정 MCP 연결됐는지 확인해줘

비교·점검 도구는 다시 볼 곳을 알려 줄 뿐이고, 같은 내용인지·적용되는지는 판정하지 않습니다. 구성원 토큰으로 여는 재무용 주소에서는 get_finance_context, get_finance_evidence, search_finance_handbook, review_finance_case가 더해져 19개입니다. 개발자용 입력 인수와 응답 필드는 docs/REFERENCE.md에 있습니다.

자주 묻는 질문

학교 공식 서비스인가요?

아닙니다. 재무팀 개인 운영 도구입니다.

가입하거나 로그인해야 하나요?

아닙니다. 공용 서버 주소는 가입·로그인 없이 씁니다. AI 앱 자체의 요금제는 각 앱의 정책을 따릅니다.

왜 npm install 이름이 없나요?

npm 레지스트리는 현재 미발행입니다. 공용 서버 주소를 쓰거나 GitHub 릴리스 tgz v0.15.8로 설치합니다.

공용 서버가 멈추면 어떻게 하나요?

공용 서버는 개인이 운영하는 장비 한 대에서 돌아가며 상시 가용성을 약속하지 않습니다. 멈췄을 때는 공식 규정 시스템을 직접 보거나 내 PC 설치를 씁니다.

캠퍼스별로 자동 검색되나요?

아닙니다. campus 값은 업무 맥락만 보존합니다. 적용범위는 원문에서 확인합니다.

다른 대학 비교는 바로 되나요?

공용 서버에서는 바로 됩니다. 내 PC에 v0.15.8을 설치했다면 DONGGUK_UNIVERSITY_COMPARISON_ENABLED=1을 넣어야 하고, 서울대는 법제처 Open API 인증키(DONGGUK_LAWGO_OC)가 더 필요합니다. 공개된 규정만 읽으며 법적 동등성을 판정하지 않습니다.

개인정보를 넣어야 하나요?

넣지 않습니다. 개인번호, 계좌, 인증정보가 든 질문은 거절합니다. 신고·지급·결재는 하지 않습니다.
