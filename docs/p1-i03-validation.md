# 인용 범위 보존과 확인필요 판정

별표·지원 범위 밖 번호를 조용히 버리고 성공 집계하지 않는다. 전체 숫자와 실제 입력 범위를 보존하며, 상세 선택자가 미지원이면 `UNSUPPORTED_CITATION`으로 남긴다.

- `별표999`, `제1조의123`, `제1조 제999항`, `제1234조`는 성공으로 세지 않는다.
- `다목적실`, 일반 명사 `서식`을 상세 인용으로 오인하지 않는다.
- `제1조제1항 및 제2항`과 `같은 조 제2항`은 바로 앞 조문의 실제 항 목록과 대조한다.
- `raw`는 기존의 짧은 규정명 + 인용 표기다. 실제 위치는 `originalRange`로 확인한다.
- 날짜 부칙 선택자의 해석과 원문 날짜 미상은 `ARTICLE_SELECTOR_UNVERIFIED`로 통일한다.
- 규정명만 쓴 정상 인용, 본칙·가지조문·부칙·제목·항 검증을 유지한다.

## 재현

```sh
npm test
node scripts/reproduce-citations.cjs citation-repros.json
node scripts/reproduce-citation-review.cjs . citation-review-repros.json
```

첫 스크립트는 기존 12개 합성 입력을, 둘째는 일반 문장·항 나열·날짜 미상 부칙과 날짜 연결 표현의 15개 입력을 실행한다. 추가 접미부 스크립트는 네 핵심 반례와 정상 대조군·범위 해석의 10개 입력을 실행한다. 검색 순위·발췌·패키지 버전·캐시 형식은 바꾸지 않는다. 실제 규정의 법적 적용성이나 배포 환경을 검증하는 테스트가 아니다. 상태·집계 의미는 [인용 검증 상태 계약](citation-integration-order.md)을 따른다. 실행 결과와 변경 반영 내역은 PR 본문에서 관리한다.


제를 생략한 호·따옴표가 있는 목·중첩 숫자 접미부는 전체 인용 범위를 보존해 확인필요 처리한다. `제1조 내지 제3조`는 제1조와 제3조를 모두 판정하고 제2조는 검증하지 않는다. 추가 재현: `node scripts/reproduce-citation-suffixes.cjs . citation-suffixes.json`.

최신 실행 수치와 검증한 commit은 PR 본문에서 관리한다.

붙여 쓴 `제1조제1항제1호가목`도 전체 인용을 보존해 확인필요로 처리한다. 호·목 전체 뒤에서 낱말 경계를 검사하므로 `다목적실`·`99호실` 등의 일반 명사는 계속 구분한다. 붙임/띄움·제 생략·따옴표 조합 128개와 날짜 연결·정상 대조군은 `node scripts/reproduce-citation-r2.cjs . citation-r2.json`으로 재현한다.

남은 한계: `제1조의 2가지 목적` 같은 수량 표현을 가지조문으로 오인하는 기존 동작은 별도 개선 대상이다.
