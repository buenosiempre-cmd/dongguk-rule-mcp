주소 하나만 넣으면 연결됩니다

내 PC에 아무것도 설치하지 않습니다. 로그인도 토큰도 없습니다. 원격 MCP 지원 여부는 앱·요금제·기관 정책에 따라 다를 수 있습니다.

공용 서버 주소

쓰는 AI 앱에 이 주소를 등록하세요

https://dgu.kr-univ-rules.com/mcp/rules

규정 도구 15개가 모두 켜져 있습니다. 접속한 곳마다 1분 60회·하루 1,000회까지 받고, 넘으면 잠시 후 다시 시도하라는 응답이 갑니다.

Claude Desktop
  1. Customize(사용자 지정) > Connectors(커넥터) 화면을 엽니다.
  2. + Add를 누르고 Add custom connector(사용자 지정 커넥터 추가)를 고릅니다.
  3. 이름은 동국 규정, 주소는 위 주소를 넣습니다.
  4. Authentication(인증) 항목에서 No sign in(로그인 없음)을 고르고 추가합니다. 이 서버는 인증이 없습니다.
  5. 새 대화를 열어 아래 첫 질문을 실행합니다.

화면이 다르면 Anthropic 공식 안내의 현재 절차를 따르세요. 메뉴 이름과 위치는 앱 버전에 따라 다를 수 있습니다. 회사·학교 계정은 관리자가 먼저 커넥터를 추가해야 할 수 있고, 요금제에 따라 추가할 수 있는 커넥터 수가 다릅니다.

ChatGPT

사용자 지정 MCP 서버를 등록하는 화면과 조건은 앱 버전, 계정, 워크스페이스 권한에 따라 다릅니다. OpenAI 공식 안내의 현재 절차대로 서버를 추가하고 같은 주소를 넣습니다. 이 서버는 인증이 없습니다. 안내에 나온 메뉴가 보이지 않으면 앱 버전, 계정 조건, 워크스페이스 관리자의 권한 설정을 확인하세요.

두 번째 선택지: 내 PC에 설치

공용 서버를 쓸 수 없거나 내 PC에서 직접 돌리고 싶을 때만 씁니다. Node.js(20.19 이상 20계열 또는 22.3 이상)와 로컬 MCP를 지원하는 AI 앱이 필요합니다.

v0.15.8 설치 파일 받기

설치 명령 보기 · 릴리스 확인

공개 규정 조회용입니다. 이 주소로는 내부 재무지식팩, 개인별 급여·계좌, 학생기록, 결재·회계 시스템에 접근할 수 없습니다. 질문에는 개인을 식별하는 정보를 넣지 마세요.

재무 도구가 필요한 구성원. 재무 업무용 도구 4개가 더해진 주소(https://dgu.kr-univ-rules.com/mcp)는 구성원 토큰이 있어야 열립니다. 토큰은 운영자(동국대 재무팀 담당자)에게 개별 요청하세요. 받은 토큰은 앱 설정의 인증 헤더(Authorization: Bearer <발급받은 토큰>)에만 넣고 문서·채팅·저장소에는 적지 않습니다.

이 질문으로 연결을 확인하세요

아래 문장을 복사해 AI에 붙여 넣고, 대괄호 안을 내 업무 조건으로 바꾸세요.

첫 질문 · 출장 규정 예시
동국 규정 MCP가 연결됐는지 버전과 도구 수를 확인해줘.
이어서 출장과 관련된 동국대 공개 규정을 찾아줘.

소속·캠퍼스: [서울 / WISE / 기타]
대상 신분: [직원 / 교원 / 강사 / 학생 / 기타]
업무 기준일: [YYYY-MM-DD]

정확한 규정명, LAW_ID, HISTORY_ID, 조문·별표 위치와
공식 원문 링크를 보여줘. 최신 개정본이 이 날짜에 적용되는지,
내 소속·신분에 적용되는지는 원문에서 별도로 확인해줘.
확인하지 못한 금액·전결권자는 확정하지 말고 확인할 사실을 적어줘.

성공 확인: 버전과 도구 수(15)가 나옴 → 규정을 찾아 옴 → 답에 실제 원문 링크가 붙음. 도구가 보이지 않으면 앱을 완전히 종료한 뒤 다시 실행해 보세요.

연결한 다음에는 바로 질문하세요

버전 확인은 처음 연결하거나 오류를 점검할 때면 충분합니다. 평소에는 규정명과 알고 싶은 내용을 함께 적어주세요.

평소 질문 · 빠른 조회
여비규정의 국내 숙박비 기준을 찾아줘.
관련 조문·별표와 원문 링크를 먼저 보여주고 핵심만 짧게 정리해줘.
근거가 부족하거나 잘렸으면 그 부분만 추가 확인해줘.

통합 조회 한 번으로 필요한 근거를 받았다면 같은 검색·본문·목차를 반복할 필요가 없습니다. 금액·권한을 실제 업무에 적용하기 전에는 아래 세 가지를 확인하세요.

3

답변을 쓰기 전, 세 가지를 확인하세요

AI의 안내를 규정 원문과 대조하면 다른 구성원도 같은 근거를 다시 찾을 수 있습니다.

CHECK 01
맞는 규정과 대상인가요?

정확한 제목과 LAW_ID를 선택하세요. 서울·WISE·직원·교원·학생에게 같은 기준이 적용된다고 가정하지 말고, 원문의 적용범위 문구를 확인합니다.

CHECK 02
그 날짜의 기준인가요?

HISTORY_ID로 개정본을 기록하세요. 개정일과 시행일은 다를 수 있습니다. 과거 사건은 부칙·경과조치까지 확인합니다.

CHECK 03
표와 조문을 직접 봤나요?

금액·권한은 해당 행·열·단위·주석을 대조하세요. 별표 누락, 발췌 잘림, 원문 조회 실패가 있으면 확인 필요로 남깁니다.

개정 비교가 더 자세해졌습니다. HWP 조문을 우선 비교하고 표 셀의 위치·병합 범위·값과 그림 파일의 변경을 보여줍니다. 그림 속 글자를 읽거나 의미·페이지 배치를 비교하는 기능은 아닙니다. HWP 대신 HTML을 사용하거나 실제 미지원·누락 항목이 있으면 부분 비교로 표시합니다.

함께 남길 근거 메모
규정명 · LAW_ID · HISTORY_ID · 기준일 · 조문/별표 위치 · 적용 대상 · 조회일 · 원문 링크 · 미확인 사항

캠퍼스별 자동 필터는 제공하지 않습니다. 캠퍼스 입력은 질문의 맥락으로 보존하며 전체 통합목록을 검색합니다. 제목과 LAW_ID를 고른 뒤 원문에서 실제 적용범위를 확인하세요.

어떻게 동작하나요

AI가 기억으로 답하는 것이 아니라, 질문할 때마다 공식 원문을 찾아 읽고 답합니다.

STEP 01
질문합니다

"여비규정에서 숙박비 기준 찾아줘"처럼 평소 말로 묻습니다. 도구 이름을 외울 필요는 없습니다.

STEP 02
AI 앱이 도구를 부릅니다

MCP는 AI 앱이 바깥 자료를 읽게 해 주는 연결 방식입니다. 앱이 질문에 맞는 도구를 골라 공용 서버에 요청합니다.

STEP 03
공용 서버가 원문을 읽습니다

누구나 볼 수 있는 rule.dongguk.edu의 공개 원문을 그때그때 조회합니다. 로그인이 필요한 자료는 읽지 않습니다.

STEP 04
조문과 출처로 답합니다

규정 이름, 조문·별표 위치, 개정일, 원문 링크가 함께 옵니다. 링크로 원문과 대조할 수 있습니다.

도구 15개가 하는 일과 예시 질문

도구는 AI 앱이 알아서 고릅니다. 모두 읽기 전용이고 공용 서버에서 모두 켜져 있습니다. 비교·점검 도구는 다시 볼 곳을 알려 줄 뿐이고, 같은 내용인지·적용되는지는 판정하지 않습니다.

필요할 때 펼쳐보세요

설치·오류 해결·CoP 실습에 필요한 추가 안내입니다.

내 PC 설치와 앱별 설정 명령

macOS 터미널 또는 Windows PowerShell을 사용합니다. 먼저 node --version으로 20.19 이상 20계열 또는 22.3 이상인지 확인합니다. 내려받은 파일이 있는 폴더에서 실행하세요.

npm install -g ./dongguk-rule-mcp-0.15.8.tgz
dongguk-rule-mcp --version
dongguk-rule-mcp --doctor --json

사용하는 앱에 맞는 설정을 출력합니다. 아래 세 명령 중 하나를 선택하세요.

dongguk-rule-mcp --print-config codex
dongguk-rule-mcp --print-config claude
dongguk-rule-mcp --print-config cursor

출력된 설정을 기존 연결을 보존하며 앱의 MCP 설정에 추가하고, 앱을 완전히 종료한 뒤 다시 실행합니다. 이 명령은 설정 예시를 출력하며 앱 설정을 직접 바꾸지 않습니다.

현재 배포본(v0.15.8)을 내 PC에 설치하면 규정 조회 도구는 바로 동작합니다. 타대학 비교와 인용 법령 조회는 앱의 MCP 서버 설정에 아래 환경변수를 넣어야 동작합니다. 넣지 않으면 그 기능만 설정되지 않았다고 답하고 규정 조회는 그대로 됩니다.

  • 타대학 비교: DONGGUK_UNIVERSITY_COMPARISON_ENABLED=1. 서울대까지 보려면 DONGGUK_LAWGO_OC(법제처 Open API 인증키)도 필요합니다.
  • 인용 법령의 원문·현행 여부: DONGGUK_LEGAL_MCP_ENABLED=1, DONGGUK_PUBLIC_LAW_LINK=1과 함께, 한국법령 MCP 주소(DONGGUK_LEGAL_MCP_TRANSPORT=streamable-http, DONGGUK_LEGAL_MCP_URL) 또는 법제처 Open API 인증키(LAW_OC, PC에 korean-law-mcp 설치 필요).

인증키는 open.law.go.kr에서 신청합니다. 공용 서버에는 이 설정이 모두 들어 있어 따로 할 일이 없습니다.

글로벌 설치가 막힌 경우, 관리자 권한 사용을 서두르기보다 전체 설치 가이드의 직접 실행 방법이나 공용 연결을 확인하세요. 기관 PC의 설치 정책은 담당 부서의 안내를 따릅니다.

다른 업무에는 어떻게 질문하나요?
  • 복무·인사: 소속과 임용 구분, 기준일을 적고 관련 규정 후보와 적용범위를 요청합니다.
  • 학사 안내: 학부·대학원·소속 과정과 기준일을 구분하고 휴학 등 해당 규정의 원문을 찾습니다.
  • 기안문 인용: 개인·내부 정보를 제거한 학습용 문장의 규정명과 조문이 실제 존재하는지 확인합니다.
  • 담당자 부재: 근거 메모의 동일 개정본·조문·별표를 다른 구성원이 다시 찾아보게 합니다.

인용이 실재한다는 결과와 해당 사안에 맞는 해석은 별개입니다. 검색 결과가 없다고 관련 규정이 없다고 단정하지 않습니다. 서로 다른 규정의 내용이 충돌하거나 적용범위가 불명확하면 담당 부서에 원문과 함께 확인합니다.

연결이 안 되거나 답변이 불완전한가요?
  • 업데이트 뒤에도 구버전: Codex의 작업을 정리하고 앱을 완전히 종료·재실행한 뒤 get_service_info를 다시 호출합니다. Aside는 공식 설정에서 도구 목록을 갱신한 뒤 실제 버전 응답까지 확인합니다.
  • 도구가 보이지 않음: 앱 재시작, 설정 문법, Node 버전과 실행 경로를 확인합니다.
  • 인증 실패: 공개 주소(/mcp/rules)는 인증이 없습니다. 주소 끝이 /mcp인 재무용 주소를 넣었는지 확인하고, 재무용 주소를 쓰는 구성원은 토큰 발급·만료 여부를 운영자에게 확인합니다.
  • 원문 조회 실패: 발생 시각과 오류코드를 기록하고 공식 규정 시스템에서 원문을 확인합니다.
  • 별표·발췌 누락: 부분 조회 상태를 남기고 원문 파일의 해당 표를 직접 확인합니다.

서버 상태 확인은 프로세스 상태를 보여줍니다. 원문 서버·앱 연결·업무 판단까지 검증하는 것은 아닙니다. 공개 오류 제보에는 버전·비식별 질문·오류코드만 남기고 인증정보나 내부 문서를 올리지 마세요.

CoP에서 20분 동안 함께 연습하기
  • 0–5분: 연결·버전·공개 원문 조회를 확인합니다.
  • 5–10분: 소속·신분·기준일을 비운 질문과 채운 질문을 비교합니다.
  • 10–15분: 조문·별표를 대조하고 근거 메모를 만듭니다.
  • 15–20분: 다른 구성원이 같은 근거를 찾고 누락·오류를 기록합니다.

설치 성공, 원문 조회 성공, 다른 담당자의 재현 성공을 따로 기록하세요. 시간절감·업무 정확성은 실증평가 가이드와 빈 평가 양식으로 측정합니다. 이 안내 페이지에 제시된 실제 업무 효과는 아직 측정되지 않았습니다.

현재 운영 범위

동국대학교의 공식 서비스가 아닙니다. 개인이 운영하는 도구로, 공개 규정 원문을 조회해 전달합니다. 공용 서버는 개인이 운영하는 장비 한 대에서 돌아갑니다. 전원·인터넷 상태 또는 공식 원문 서버 장애에 따라 중단될 수 있습니다. 학교의 공식 해석, 전 구성원 계정 개통, 상시 가용성 또는 현업 효과가 검증되었다는 의미는 아닙니다.
