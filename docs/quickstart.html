연결 방법을 하나 고르세요

AI 앱이 MCP 연결을 지원해야 합니다. 앱·요금제·기관 정책에 따라 사용 가능 여부가 다릅니다.

공용 서버 연결

내 PC에 서버 설치 없이

운영자가 서버를 관리합니다. 먼저 개인 또는 그룹에 배정된 인증정보를 받으세요.

https://dgu.kr-univ-rules.com/mcp/rules
  1. 사용하는 AI 앱의 원격 MCP 연결 설정을 엽니다.
  2. 위 주소와 운영자가 발급한 인증정보를 입력합니다.
  3. 연결을 저장하고 아래 첫 질문을 실행합니다.

인증정보가 아직 없으면 CoP 또는 서비스 운영 담당자에게 발급을 요청하세요. 관리자 토큰을 다른 구성원과 공유하지 않습니다.

개인 PC 설치

공유 토큰 없이 직접 시작

Node.js 20.19 이상과 로컬 MCP를 지원하는 AI 앱이 필요합니다. 공개 규정만 조회하는 기본 설정으로 시작합니다.

v0.10.0 설치 파일 받기
  1. GitHub의 고정 버전 설치 파일을 받습니다.
  2. 아래 설치 명령과 앱별 설정 출력을 확인합니다.
  3. AI 앱을 다시 시작하고 첫 질문을 실행합니다.

개인 설치 명령 보기 · 릴리스 확인

공개 규정 조회용입니다. 이 연결로 내부 재무지식팩, 개인별 급여·계좌, 학생기록, 결재·회계 시스템에 접근할 수 없습니다. 질문에는 개인을 식별하는 정보를 넣지 마세요.

2

이 질문으로 연결을 확인하세요

아래 문장을 복사해 AI에 붙여 넣고, 대괄호 안을 내 업무 조건으로 바꾸세요.

첫 질문 · 출장 규정 예시
동국 규정 MCP의 get_service_info로 연결과 버전을 확인해줘.
이어서 lookup_dongguk_rule로 출장 관련 공개 규정을 찾아줘.

소속·캠퍼스: [서울 / WISE / 기타]
대상 신분: [직원 / 교원 / 강사 / 학생 / 기타]
업무 기준일: [YYYY-MM-DD]

정확한 규정명, LAW_ID, HISTORY_ID, 조문·별표 위치와
공식 원문 링크를 보여줘. 최신 개정본이 이 날짜에 적용되는지,
내 소속·신분에 적용되는지는 원문에서 별도로 확인해줘.
확인하지 못한 금액·전결권자는 확정하지 말고 확인할 사실을 적어줘.

성공 확인: 서버 버전 확인 → 도구 호출 성공 → 실제 원문 링크 확인. 설치 성공이나 서버 상태 응답만으로 원문 조회 성공을 판정하지 않습니다.

3

답변을 쓰기 전, 세 가지를 확인하세요

AI의 안내를 규정 원문과 대조하면 다른 구성원도 같은 근거를 다시 찾을 수 있습니다.

CHECK 01
맞는 규정과 대상인가요?

정확한 제목과 LAW_ID를 선택하세요. 서울·WISE·직원·교원·학생에게 같은 기준이 적용된다고 가정하지 말고, 원문의 적용범위 문구를 확인합니다.

CHECK 02
그 날짜의 기준인가요?

HISTORY_ID로 개정본을 기록하세요. 개정일과 시행일은 다를 수 있습니다. 과거 사건은 부칙·경과조치까지 확인합니다.

CHECK 03
표와 조문을 직접 봤나요?

금액·권한은 해당 행·열·단위·주석을 대조하세요. 별표 누락, 발췌 잘림, 원문 조회 실패가 있으면 확인 필요로 남깁니다.

함께 남길 근거 메모
규정명 · LAW_ID · HISTORY_ID · 기준일 · 조문/별표 위치 · 적용 대상 · 조회일 · 원문 링크 · 미확인 사항

캠퍼스별 자동 필터는 제공하지 않습니다. 캠퍼스 입력은 질문의 맥락으로 보존하며 전체 통합목록을 검색합니다. 제목과 LAW_ID를 고른 뒤 원문에서 실제 적용범위를 확인하세요.

필요할 때 펼쳐보세요

설치·오류 해결·CoP 실습에 필요한 추가 안내입니다.

내 PC 설치와 앱별 설정 명령

macOS 터미널 또는 Windows PowerShell을 사용합니다. 먼저 node --version으로 20.19 이상인지 확인합니다. 내려받은 파일이 있는 폴더에서 실행하세요.

npm install -g ./dongguk-rule-mcp-0.10.0.tgz
dongguk-rule-mcp --version
dongguk-rule-mcp --doctor --json

사용하는 앱에 맞는 설정을 출력합니다. 아래 세 명령 중 하나를 선택하세요.

dongguk-rule-mcp --print-config codex
dongguk-rule-mcp --print-config claude
dongguk-rule-mcp --print-config cursor

출력된 설정을 기존 연결을 보존하며 앱의 MCP 설정에 추가하고, 앱을 완전히 종료한 뒤 다시 실행합니다. 이 명령은 설정 예시를 출력하며 앱 설정을 직접 바꾸지 않습니다.

글로벌 설치가 막힌 경우, 관리자 권한 사용을 서두르기보다 전체 설치 가이드의 직접 실행 방법이나 공용 연결을 확인하세요. 기관 PC의 설치 정책은 담당 부서의 안내를 따릅니다.

다른 업무에는 어떻게 질문하나요?
  • 복무·인사: 소속과 임용 구분, 기준일을 적고 관련 규정 후보와 적용범위를 요청합니다.
  • 학사 안내: 학부·대학원·소속 과정과 기준일을 구분하고 휴학 등 해당 규정의 원문을 찾습니다.
  • 기안문 인용: 개인·내부 정보를 제거한 학습용 문장의 규정명과 조문이 실제 존재하는지 확인합니다.
  • 담당자 부재: 근거 메모의 동일 개정본·조문·별표를 다른 구성원이 다시 찾아보게 합니다.

인용이 실재한다는 결과와 해당 사안에 맞는 해석은 별개입니다. 검색 결과가 없다고 관련 규정이 없다고 단정하지 않습니다. 서로 다른 규정의 내용이 충돌하거나 적용범위가 불명확하면 담당 부서에 원문과 함께 확인합니다.

연결이 안 되거나 답변이 불완전한가요?
  • 도구가 보이지 않음: 앱 재시작, 설정 문법, Node 버전과 실행 경로를 확인합니다.
  • 인증 실패: 공용 연결의 자격증명 발급·만료 여부를 운영자에게 확인합니다.
  • 원문 조회 실패: 발생 시각과 오류코드를 기록하고 공식 규정 시스템에서 원문을 확인합니다.
  • 별표·발췌 누락: 부분 조회 상태를 남기고 원문 파일의 해당 표를 직접 확인합니다.

서버 상태 확인은 프로세스 상태를 보여줍니다. 원문 서버·앱 연결·업무 판단까지 검증하는 것은 아닙니다. 공개 오류 제보에는 버전·비식별 질문·오류코드만 남기고 인증정보나 내부 문서를 올리지 마세요.

CoP에서 20분 동안 함께 연습하기
  • 0–5분: 연결·버전·공개 원문 조회를 확인합니다.
  • 5–10분: 소속·신분·기준일을 비운 질문과 채운 질문을 비교합니다.
  • 10–15분: 조문·별표를 대조하고 근거 메모를 만듭니다.
  • 15–20분: 다른 구성원이 같은 근거를 찾고 누락·오류를 기록합니다.

설치 성공, 원문 조회 성공, 다른 담당자의 재현 성공을 따로 기록하세요. 시간절감·업무 정확성은 실증평가 가이드와 빈 평가 양식으로 측정합니다. 이 안내 페이지에 제시된 실제 업무 효과는 아직 측정되지 않았습니다.

현재 운영 범위

공용 서버는 Mac mini에서 운영됩니다. 잠자기·전원·인터넷 상태 또는 공식 원문 서버 장애에 따라 중단될 수 있습니다. 학교의 공식 해석, 전 구성원 계정 개통, 상시 가용성 또는 현업 효과가 검증되었다는 의미는 아닙니다.
