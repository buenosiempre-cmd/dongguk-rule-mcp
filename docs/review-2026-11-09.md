# 점검 및 수정 (v0.12.3)

기준일: 2026-11-09. GitHub `main`(`6db33f7`, v0.12.2)에서 오프라인 테스트, `--doctor --live`, 실사이트 스모크와 함께 실제 질문 형태의 도구 호출을 점검했다.

## 발견한 오류와 수정

| 증상 (수정 전, 실사이트) | 원인 | 수정 |
|---|---|---|
| `get_rule_content(law_id=184, article=1)` → `AMBIGUOUS_ARTICLE`(제1조 10개). 여비규정 제1조를 읽을 수 없음 | 원문 HTML의 부칙 머리글 `div.addenda`를 파서가 버려 부칙 조문이 본칙으로 분류됨 | `parseContent`가 부칙 머리글을 `## 부칙 (개정일)`로 보존 |
| `verify_rule_citations("여비규정 제2조")` → ⚠ 확인필요(제2조 5개) | 같은 원인 | 위와 동일. 본칙 제2조가 ✓ 실존으로 판정됨 |
| `get_rule_toc`에 부칙 구분 없이 `제1조(시행일)`이 반복 | 같은 원인 | 목차에 부칙 머리글 표시 |
| `article: "부칙 제1조"` 모호 오류가 "개정일을 선택하라"고 안내하지만 지정 방법이 없음 | 선택자에 부칙 개정일 입력이 없음 | `부칙(2024.8.27.) 제1조`, `부칙 2024-08-27 제1조` 지원. 오류 메시지·후보에 바로 쓸 수 있는 선택자 표시 |
| `search_rule_deep("출장 숙박비 상한")` → NOT_FOUND (`숙박비`는 4건) | 원문 전문검색은 모든 단어를 AND로 찾으므로 원문에 없는 단어 하나로 0건 | 0건이면 핵심어로 재검색하고, 끝 단어부터 하나씩 빼며 최대 3회(35초 예산) 순차 재시도. 제외한 단어를 결과에 명시 |
| `lookup_dongguk_rule("교원 연구년 신청 자격은?")` → 20초 후 NOT_FOUND | 질문 전체(조사·물음표 포함)를 검색어로 사용 | 조사·질문 상투어를 제거한 핵심어로 전문검색. 약 11초에 전임교원 인사규정 시행세칙 등 후보 반환 |
| 제목이 전혀 일치하지 않아도 "여러 규정 후보가 있습니다" 안내 | 본문 검색 후보와 제목 후보를 같은 문구로 안내 | `matchType:"none"`이면 "제목이 일치하는 규정은 없고 본문 검색 후보"임을 밝히고 텍스트에도 후보 목록 표시 |

본문 파싱 결과가 바뀌었으므로 30일 디스크 캐시 이름을 `content-v3`로 올렸다. 이전 캐시의 부칙 누락 본문을 다시 쓰지 않는다.

병렬 단어별 검색은 원문 서버가 요청당 9~18초 걸려 20초 시간 제한을 넘겨 채택하지 않았다.
