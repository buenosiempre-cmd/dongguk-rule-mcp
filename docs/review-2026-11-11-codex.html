동국규정 MCP v0.12.3 검수

자연어 규정 조회가 정확한 다단어 전문검색 결과를 건너뛰는 회귀를 찾아 수정했습니다.

수정 및 재검증 완료

대상: 로컬 maintenance/2026-11-09 브랜치 · 기준 커밋 f71a1d9

우선 조치

수정된 검색 로직과 회귀 테스트를 검토한 뒤 기존 브랜치에 반영하면 됩니다. 원격 게시와 실행 중 MCP 교체는 아직 확인되지 않았습니다.

발견과 수정

규정명이 없는 출장 숙박비 같은 두 단어 질문은 제목 검색이 실패하면 전문검색으로 넘어갑니다. 기존 코드에서는 핵심어와 원문이 같을 때 그 조합을 재시도 목록에서 제외했습니다. 따라서 정확한 다단어 전문검색 결과가 있어도 출장 또는 숙박비처럼 넓은 검색을 먼저 수행했습니다.

통합 조회에서는 정확한 조합을 먼저 시도하도록 했습니다. search_rule_deep은 이미 원문 조합을 조회하므로 중복 요청을 계속 피합니다.

검증 근거

  • 합성 캐시에 다단어 전문검색 결과를 넣은 MCP 회귀 테스트: 수정 전 UPSTREAM_FORMAT_CHANGED로 실패, 수정 후 통과.
  • npm test: 전체 오프라인 테스트 통과(종료 코드 0).
  • node test/smoke-live.js: 공개 규정 실사이트 9개 항목 통과. 캐시와 쿠키를 사용하지 않고 HWP 조회, HTML 본문, 목차, 연혁, 비교, 깊이 검색을 확인.
  • git diff --check: 공백 및 패치 형식 오류 없음.
실사이트 스모크는 대표 규정 1건의 연결 상태를 확인합니다. 새 다단어 경로의 분기와 후보 선택은 외부 사이트 상태에 흔들리지 않는 MCP 합성 테스트로 검증했습니다.

검토 범위와 남은 확인

기존 v0.12.3의 부칙 파싱·날짜 선택 로직은 코드와 회귀 테스트를 대조했고 전체 테스트에서 통과했습니다. 이번 수정은 자연어 검색 재시도 경로 두 곳과 회귀 테스트에 한정됩니다. 설치된 MCP 클라이언트의 버전이나 원격 브랜치 상태는 이 로컬 검증만으로 갱신되지 않습니다.
