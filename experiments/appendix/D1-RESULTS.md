## 2. 전체 513규정의 별표 후보 신호 실험

**이 절은 운영 MCP strict70/71과 별개인 dense-only 후보 평가다.** 운영의 낱말·범위·fusion·실제 발췌를 거치지 않는다. 같은 입력 corpus/벡터라는 사실만으로 같은 지표가 되는 것은 아니다.

사전 고정 정책: 질문당 임베딩 1회 → D1 조문별 조각 최고 cosine → 규정별 최고 cosine 상위3 → 규정당 증거 상위3. 가중치/동의어/질문 표현을 조정하지 않았다. 별표 43청크를 9,790조문 후보에 넣어 기존 조문과 실제로 경쟁시킨다. 그래프 연결은 D1 corpus에서 재생성하지만 별도 가점은 주지 않는다.

- **D1 dense**: 기존 11,422벡터, 9,790조문만.
- **D1 + 좌표표**: 같은 D1 후보에 기존 HWP 좌표 목록을 400자/100자 겹침으로 자른 24청크 추가.
- **D1 + kordoc**: 같은 D1 후보에 GFM 행·주석 43청크 추가.

후보 근거 적중은 상위3 규정의 증거 상위3 안에 정답 조문/별표 식별자가 있는지 채점한다. 실제 반환 본문의 표제 검사와는 다르다. 신규 dev의 행 근거는 기대 항목·금액/등급이 한 청크에 공존하는지 검사하고 kordoc은 정답 행 번호도 요구한다. 기존 좌표표는 토큰 공존 상한 추정이며 실제 답변 생성 점수가 아니다.
