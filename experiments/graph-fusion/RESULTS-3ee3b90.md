## 사전에 고정한 하향 가점

hybrid 상위 3규정의 seed 점수는 1, 1/2, 1/3이다. 명시적 `implements`의 저장방향(하위→상위)을 반대로 탐색해 큰 규정→시행세칙·내규만 가점한다. 상위의 본칙 블록 수가 하위보다 많고, 하위 제목이 시행세칙/내규로 끝나야 한다. 단순 제목 유사성은 위계 근거가 아니다.

기존 그래프 API `rankRelatedRules`를 위계 간선만 남긴 그래프에 호출하고 방향을 다시 검사한다. 상향·일반 인용·준용·별표·개정 관계는 가점 0이다. 후보에 없는 대상, 명시적 캠퍼스/기관 불일치, 버전 불일치도 제외한다. 그래프 신호를 최대 1로 제한해 `hybrid 점수 × (1 + 0.25 × 신호)`로 계산한다. 결과를 보고 계수·seed 수·허용 방향을 조정하지 않았다.

그래프는 corpus 객체마다 한 번 로드하거나 생성한다. 네트워크·디스크 쓰기를 하지 않는다. corpus/그래프 실패 시 가점 0으로 hybrid 순서를 보존하며 audit에 상태를 기록한다.
