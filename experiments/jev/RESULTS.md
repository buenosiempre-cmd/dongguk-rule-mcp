# JEV 검색 실험 결과 — 2026-11-27

**판단: RRF를 보완할 후보로 유지하되, 바로 교체하거나 단독 확정 기준에 쓰지 않는다.** 규정 그룹 교차검증에서 선택 조문 적중은 83.1%→90.1%(+5건)로 개선됐다. 반면 규정 top1은 1건 감소했고, 기존 train46→dev25의 선택 조문 적중은 양쪽 모두 20/25로 같았다. 사용자에게 반환할 상위 규정의 확률 보정 오차도 남아 있다.

다음 우선 조치는 ① 생산 경로와 동일한 낱말 점수·발췌를 통한 비교 ② 사용자 작성 keywords를 가진 공개 문항 평가 ③ 동국규정팀의 미사용 보류셋 검증이다. 본 실험에서는 보류셋을 열거나 요청하지 않았다. main 병합·릴리스·배포는 하지 않았다.

## 공개 문항 비교

입력은 저장소의 공개 train 46개 + dev 25개 = **71개**이며 질문만 사용했다. 정답 규정 공유·대체정답·동일 질문을 연결한 **24그룹, 외부 5-fold** 평가다. 규정 보정기는 내부 3-fold 조문 예측으로 학습했다. 모든 비교에서 같은 corpus·기존 e5-small q8·최대 조문 점수 규정 집계를 사용했다.

선택 조문 적중의 개선 문항은 A02, A12, A23, T02, H25이며 개선 5건·악화 0건·동률 66건이다. 그룹 부트스트랩 2,000회의 차이 구간은 +2.44~+11.84%p였다. 공개 개발 문항의 작은 표본에 대한 탐색 결과이며 미사용 보류셋의 개선을 보증하지 않는다.

기본 RRF와 확장 RRF 모두 후보에 정답이 71/71건 있었다. 이 표본에서 이득은 후보 누락 해소보다 순위·조문 선택 변화에서 나왔다. 확장 RRF만으로는 오히려 59→57건으로 감소했다.

**기존 46개 학습 → 25개 개발 검증:** 규정 top3 RRF 21/25→JEV 22/25, 선택 조문 적중은 20/25→20/25. 이 분리에서는 dev 19/25개가 train과 정답 규정을 공유한다. OOF 개선과 이 결과를 함께 해석해야 한다.

## 대사와 남은 한계

입력 46+25=71개, 출력 OOF 71개, ID 누락·중복 0개로 일치했다. 기본 RRF 선택 적중 59건+오답 12건=71건, JEV 64건+오답 7건=71건, 차이 +5건과 문항별 개선 5건·악화 0건이 일치한다. 금액 자료는 없다.

질문+핵심어 평가는 공개 fixture에 사용자 keywords가 없어 미실시했다. 정답에서 키워드를 만들지 않았다. 실험 BM25는 기존 corpus·개념 사전을 사용하는 어댑터이며 생산 `searchCorpus` 점수와 같지 않다. 조문 선택 평가는 실제 발췌 본문 채점과 같지 않다. 90.1%는 95% 목표 달성이 아니며 즉시 배포 근거로 사용하지 않는다.
